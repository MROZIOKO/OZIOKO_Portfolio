# Paul Ozioko — Teaching Portfolio

A responsive professional portfolio website for Mathematics, Computer Science, programming, machine learning, robotics and physical-computing work.

## Replace the placeholders

1. In `index.html`, replace `your.email@example.com` with your professional email.
2. Replace every `href="#"` with the correct GitHub, LinkedIn, project, resource or case-study link.
3. Replace the portrait and project placeholder blocks with image elements. Example:

```html
<img src="assets/images/profile.jpg" alt="Paul Ozioko, Mathematics and Computer Science teacher">
```

4. Add your PDF CV at `assets/Paul-Ozioko-CV.pdf` and update the two CV links in `index.html`.
5. Replace all `XX` impact figures with accurate, verifiable evidence.
6. Review the experience, qualifications and professional-development details.
7. Remove student names and identifying details unless you have explicit permission to publish them.
8. Add certificate scans to `assets/certificates/`, replace the certificate placeholder links, and redact sensitive registration numbers, signatures, dates of birth and private QR codes.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `teaching-portfolio`.
2. Upload all the files and folders in this project.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. GitHub will display the public website address after deployment completes.

## Local preview

Open `index.html` in a browser. For the most accurate preview, use a simple local server such as the Live Server extension in Visual Studio Code.
